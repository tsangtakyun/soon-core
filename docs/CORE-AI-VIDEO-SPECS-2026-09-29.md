## 儲存與隔離要求

三款方向只可新增為 **Core-only review**。不得修改現有已發布版本，不得建立 active template binding，亦不得在 Creator 或 Content Studio 顯示為可生成方向。

| 欄位 | 固定值 |
| --- | --- |
| `status` | `review` |
| `creator_eligible` | `false` |
| `content_studio_enabled` | `false` |
| `generation_enabled` | `false` |
| `template_binding_allowed` | `false` |
| active binding | 0 |
| reference playback | 關閉；所有原片權利尚未核實 |

規格描述的是內容結構、資產要求及品質標準。它不代表 SOON 已接駁生成工具、能自動生成影片，亦不代表已取得 reference 的再發布權。

## 01 AI 荒誕反轉微劇

- Code：`ai_absurd_twist_microdrama`
- 格式：AI 短片，9:16，1080 × 1920
- 時長：8–20 秒，理想 12 秒
- 定位：在一個場景內，以一條清楚動作線建立預期，再用反常結果完成笑點或驚奇。
- 適用：誤會對白、徒勞反轉、工作被破壞、物件／角色狀態變形、明確虛構的禁忌揭示。
- 不適用：純粹漂亮變形、需要長篇背景才明白、危險挑戰、可能被誤認為真實新聞或衛生事件的內容。

### 結構與時長

| 段落 | 建議時間 | 作用 |
| --- | ---: | --- |
| 處境與主體 | 0–2 秒 | 首幀交代角色、地點和正在進行的事 |
| 動作與預期 | 2–7 秒 | 只推進一條主要動作，令觀眾形成預期 |
| 反轉／揭示 | 7–11 秒 | 結果直接改寫前面行動的意義 |
| 反應與停留 | 11–12 秒 | 保留角色反應或結果全貌，讓笑點落地 |

實際片長可以伸縮，但反轉應位於最後 20–35%，而且靜音觀看仍能理解主要因果；只有對白誤會變體可以讓語音承擔主要笑點。

### 資產與一致性

- 角色：每個主要角色要有正面、側面、全身、表情和服裝設定；動物／擬人角色要固定毛色、比例和服裝。
- 場景：只用一個主要空間；建立左右位置、入口、背景人物和主要家具圖。
- 道具：列明開始狀態、互動狀態和結果狀態；數量、顏色、尺寸及相對位置不可變。
- 一致性：角色身份、四肢、眼神、服裝、空間方向、接觸點、道具數量和結果狀態逐鏡核對。

### 鏡頭、聲音與字幕

- 優先一個完整主鏡，或 2–4 個因果連續的鏡頭；不可用切鏡掩蓋故事斷裂。
- 轉場以動作承接或直接切換為主；不使用與笑點無關的特效轉場。
- 無旁白版本以環境聲、動作聲和角色反應為主；對白版本限制在 6–9 句內。
- 字幕使用繁體中文；畫面下方安全區、最多兩行。模型生成的畫面文字一律不用，字幕後期加入。

### 素材不足處理

- 缺角色多角度參考：停止動態生成，先補角色設定圖。
- 缺結果狀態圖：先批准首幀與尾幀，再做中段動態。
- 接觸或肢體不穩：縮短動作、拆鏡或改用反應鏡；不得把明顯錯誤當荒誕風格。
- 權利不明：保留文字規格，不顯示原片、不複製聲音或水印。

### 品質驗收

1. 首 2 秒能看懂角色、地點和任務。
2. 全片只有一條主要因果，反轉清楚否定或改寫預期。
3. 角色、服裝、肢體、道具和空間方向連續。
4. 手／爪、液體、餐具、窗戶等接觸沒有穿插、漂浮或突然消失。
5. 聲音、嘴形和字幕意思一致；靜音版本仍可理解主要故事。
6. 涉及兒童、動物、衛生或危險行為時明確標示 AI／虛構，不鼓勵模仿。

## 02 AI 多角色連續情境短劇

- Code：`ai_continuity_ensemble_skit`
- 格式：AI 短片，9:16 為標準；橫向只作經批准的變體
- 時長：60–180 秒，首個驗證版本應為 45–60 秒、3 場、2 個主要角色
- 定位：固定角色群在多個日常情境反覆互動，每場證明同一個角色設定，最後完成情感、喜劇或公益資訊主線。
- 適用：家庭／同事／朋友關係喜劇、角色觀點反差、經專業核對的公益情境短劇。
- 不適用：一次性視覺笑點、沒有固定角色關係的片段合集、未經核對的醫療／安全／法律指示。

### 結構與時長

| 段落 | 建議時間 | 作用 |
| --- | ---: | --- |
| 高概念設定 | 0–6 秒 | 一句說明角色關係與反常規則 |
| 情境一 | 6–20 秒 | 用最簡單場景證明角色規則 |
| 情境二 | 20–36 秒 | 換場景並升級衝突；角色行為保持一致 |
| 情境三 | 36–52 秒 | 加入後果、外人或資訊要求 |
| 角色轉折 | 52–58 秒 | 由笑點轉到真正價值／正確行動 |
| 收束 | 58–60 秒 | 一句回扣，不另開新議題 |

長版可增加情境，但每一場只承擔一個角色證據或一個安全重點。

### 資產與一致性

- 角色聖經：姓名／編號、年齡、關係、身高比例、面部特徵、髮型、服裝組、聲線、說話方式、不可變特徵。
- 場景聖經：每個場景的平面方向、門窗、主要家具、光線、時間和固定道具。
- 對白資產：逐角色劇本、情緒、停頓、字幕版和必要事實來源。
- 視覺資產：正面、側面、全身、表情組、雙人同框比例、常用動作和每場關鍵首尾幀。
- 一致性：跨場保持人物身份、年齡、聲線及核心服裝；換裝必須由劇情交代。對話場固定視線、左右關係和背景方向。

### 鏡頭、聲音與字幕

- 每場最少有環境建立鏡、對話主鏡和反應鏡；插鏡只用於證明道具、行動或遮接口型。
- 轉場依時間或地點改變，使用直接切換、聲音先行或動作匹配；不可用炫技轉場代替因果。
- 每名角色使用固定聲線；若口型不穩，改用背面、側面、反應鏡或插鏡，不把不同步鏡頭硬留。
- 對白可自然口語；字幕統一繁體中文書面語，最多兩行。英文只在項目需要時另加。

### 素材不足處理

- 缺角色聖經：不得開始跨場動態生成。
- 單場人物失真：只重做該鏡，不以全片另一張臉補上。
- 對白太長：先改劇本或拆反應鏡，不用加速聲音壓縮。
- 事實或安全來源不足：刪除具體指示，標記 `fact_review_required`，保持 review 狀態。
- 原片權利不足：只保留結構摘要，不嵌入片段、聲音或新聞版面。

### 品質驗收

1. 首 6 秒講清角色關係和全片規則。
2. 每場只有一個主要衝突或資訊點，並與同一角色設定有關。
3. 角色臉、年齡、聲線、服裝和身高比例跨場一致。
4. 對話視線、嘴形、反應時間和左右關係合理。
5. 場景格局、食物、手機、餐具和其他道具不會無故改變。
6. 結尾由前面情境自然推導，沒有突然說教。
7. 公益內容每一項行動均附權威來源及人工專業審核。

## 03 AI 實景主持穿越導覽

- Code：`ai_host_time_travel_tour`
- 格式：AI／真人混合短片，9:16，1080 × 1920
- 時長：75–150 秒，理想 105 秒
- 定位：保留真人主持的身份、聲音和 vlog 語言，把主持放入人工智能重建的歷史、科學或原創幻想環境，依空間順序帶觀眾參觀。
- 適用：已消失城市空間、歷史建築、考古場景、科學尺度、資料充分的原創重建世界。
- 不適用：以獵奇方式重演災難、把生成畫面冒充史料、欠缺資料卻聲稱精準還原、直接套用第三方影視 IP。

### 結構與時長

| 段落 | 建議時間 | 作用 |
| --- | ---: | --- |
| 現場證明 | 0–8 秒 | 主持與重建世界同框，交代年代／地點及 AI 重建屬性 |
| 入口與規則 | 8–22 秒 | 展示如何進入及一項必要規則 |
| 第一站 | 22–42 秒 | 主持反應＋可見環境證據 |
| 第二站 | 42–65 秒 | 空間推進＋一項經核實資料 |
| 第三站 | 65–88 秒 | 人物／物件互動，建立世界生活感 |
| 私密或細節空間 | 88–105 秒 | 房間、工具、日常細節或比例證據 |
| 全貌與回扣 | 105–120 秒 | 闊景、路線回顧、資料限制及克制收尾 |

### 資產與一致性

- 主持：有授權的乾淨原片、正側面身份參考、髮型、眼鏡、衣服、聲音及常用手勢；不得使用未授權真人聲線。
- 世界：年代／地點研究包、地圖與導覽順序、建築及室內設定、服裝群、交通工具、道具、標誌和禁用元素。
- 場景：每一站的入口、出口、相鄰關係、光線和人流；主持移動方向必須符合地圖。
- 歷史證據：每個可驗證句子對應來源；生成重建與真實照片分開標示。
- 一致性：主持臉、眼鏡、髮型、衣服、膚色、自拍手臂和相機高度跨鏡固定；背景年代、群眾服裝、建築、文字及空間方向一致。

### 鏡頭、聲音與字幕

- 使用自拍近鏡、主持回頭揭示、步行跟拍、環境闊景、物件／房間近鏡和路線過場。
- 轉場只在主持實際移動到另一站、時間改變或環境層級改變時使用；保留入口／走廊／樓梯等空間連接證據。
- 主持同期講述為主，背景環境聲支援現場感；旁白只補不能在場景自然說出的資料。
- 字幕用繁體中文書面語，最多兩行；年代、地名和 AI 重建標示另設固定字卡。

### 素材不足處理

- 缺主持授權或乾淨素材：停止身份生成，不使用社交平台下載片代替。
- 缺地圖或空間資料：把內容改成「概念重建」並減少精準導覽聲稱；不可虛構可行路線。
- 缺可靠歷史來源：刪除具體年代／功能描述或標示尚待核實。
- 主持身份漂移：縮短鏡頭、改用背面／POV／環境鏡，或重新建立身份參考；不可接受不同臉。
- 群眾和互動失真：降低互動複雜度，將對話改成主持觀察；不可用錯誤肢體鏡頭。

### 品質驗收

1. 開場明確標示 AI 重建，不會被誤認為真實歷史攝影。
2. 主持身份、衣服、眼鏡、聲線和相機高度全片一致。
3. 導覽路線符合地圖；入口、樓梯、走廊和房間關係能夠理解。
4. 年代服裝、建築、交通、道具和可見文字沒有明顯錯置。
5. 每站只有一個重點，主持反應與可見證據同時出現。
6. 每個歷史或科學聲稱有來源；推測和藝術處理明確標示。
7. 災難、死亡或受害者題材經編輯審核，以教育與理解為目的。
8. 沒有未授權第三方角色、美術、對白、音樂、商標或真人聲線。

## 既有方向與研究項目

### 05 名畫人物走入現實

- 不新增方向。
- 建議 merge target：`ai_artist_reflective_monologue` 的下一個 review 版本；不得直接改現有 published 版本。
- 模組名稱：`artwork_walks_into_reality`。
- 用途：作開場、作品意象或段落轉場；同一背景和運鏡下依次出現藝術家／作品人物。
- 權利：即使原作屬公有領域，特定掃描、攝影、當代演繹、音樂和生成影片仍要分開核對。原片不可公開播放。

### 06 空間破界奇觀

- 不建立內容方向或模板。
- 研究代碼：`space_boundary_spectacle`。
- 用途：先建立正常空間，再讓單一元素逐級跨越原有邊界，最後以人物或物件反應提供尺度。
- 原片有工具宣傳字樣，只可作內部效果研究。

### 08 第一身幻想學校

- 不建立方向，不掛原片。
- 只保留抽象方法：`original_fantasy_world_pov`。
- 若日後有 2–3 條完全原創、無第三方 IP 的 reference，才重新評估方向。

### 09 民俗角色消防短劇

- Merge target：`ai_continuity_ensemble_skit` 的 `public_service_folklore_reversal` 變體。
- 現檔為新聞轉載，原始來源、再發布權和完整安全依據未確認；不得掛公開可播放 reference。
- 所有消防、微波爐、濕手用電及電動車充電指示必須按適用地區官方資料逐項核對。
